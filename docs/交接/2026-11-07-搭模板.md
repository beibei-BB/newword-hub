# 交接：搭新词主站模板（Codex）

**要做什么**：搭一个能反复用的新词主站模板。以后上一个新词，只要跑一条命令生成页面、写这个词的工具功能、填文案，就能上线。

## 技术
- Astro（静态）+ Cloudflare Pages，和纹身站一样（参考 `beibei-BB/tattoo-stencils`）
- 工具功能用 Astro 岛（只在工具组件里加载 JS），整页要快
- 站点设置集中在一个文件 `src/site.config.ts`：站名、正式域名（先空着）、联系邮箱、主色、Cloudflare 统计 token、广告开关和广告代码、商标黑名单
- **正式域名为空时，全站加 `noindex`**，免得 pages.dev 预览地址先被收录

## 页面
| 页面 | 要点 |
|---|---|
| 首页 `/` | 主站介绍 1 段 + 所有新词页的卡片（从数据自动生成，新的在前） |
| 新词页 `/<slug>/` | 首屏：H1 + 一句话说明 + **工具组件**；下面：怎么用（3～5 步）、FAQ（3～6 条，带 FAQ 结构化数据）、相关工具（同站其他新词页）、分享按钮；可选"与 XX 品牌无关"声明 |
| `/about/`、`/privacy/`、`/contact/` | 申请 AdSense 要用，文案先写通用版 |
| `/blog/` + 文章页 | 列表 + 一篇示例文章 |
| 404 | 必须有 |

- 每个新词页的文案放 `src/content/tools/<slug>.md`（标题、描述、H1、怎么用、FAQ、相关、品牌声明），工具组件放 `src/tools/<slug>/`
- 自动生成：sitemap、robots.txt、canonical（指正式域名）、OG 标签

## 脚本
- `npm run new-tool <slug>`：生成文案文件和工具组件空壳
- `npm run check`：上线前检查——每页 1 个 H1；标题 ≤ 60 字符、描述 ≤ 160、全站不重复；站内 0 死链；图片都有 alt；about / privacy / contact / 404 存在；有手机 viewport；**网址和站名里没有出现商标黑名单里的词**

## 广告和统计
- `<AdSlot>` 组件：新词页工具下方 1 个、FAQ 下方 1 个；广告开关关着时不占位置
- Adsterra、AdSense 代码以后填进 `site.config.ts`，组件照着插入
- Cloudflare Web Analytics：填了 token 就加载

## 示例
做一个示例新词页 `/text-repeater/`（输入文字、重复次数，输出结果、可复制），用来验证整套流程。

## 验收标准
1. `npm run build` 通过，`npm run check` 全绿
2. 用 `npm run new-tool demo-two` 能生成第二个页面，首页和相关推荐自动出现它
3. 示例页手机宽度（375px）下首屏能直接用工具
4. 正式域名为空时页面有 noindex；填上域名后 canonical 和 sitemap 都指正式域名
5. 广告开关关闭时没有空白占位

## 不要动
- 视觉风格先用简洁默认（白底、一个主色、系统字体），**不要花时间打磨样式**，Claude 验收时再定
